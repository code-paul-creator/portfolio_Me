## 💻 How to Preview Locally

Open `index.html` directly in your browser:
```bash
# On macOS:
open index.html

# Or using Python local server:
python3 -m http.server 8000
# Then visit: http://localhost:8000
```

## 🌐 How to Deploy to GitHub Pages

1. Push these files to a repository on GitHub (e.g. `paulami-portfolio` or `among-us-portfolio`).
2. Go to **Settings** > **Pages** in your repository.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Within 1–2 minutes, your Among Us portfolio will be live at:
   `https://code-paul-creator.github.io/<repo-name>/`
